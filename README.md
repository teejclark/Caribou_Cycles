# Caribou_Cycles

This repository contains code needed to reproduce the results:

T.J. Clark-Wolf, Jack St. John, Chandni A. Rajesh, and Mark Hebblewhite:
**"Increasing environmental variability inhibits evolutionary rescue in a long-lived vertebrate"**,
accepted for Ecoplogy and Evolution.

All analyses were done in `R`. The code to conduct the IPM2 is in the `Code` folder, whereas data is in the `Data` folder.
